# CoC 世界视觉参考

本目录中的 JPG 来自 Supercell 官方页面，仅用于帮助维护者理解主世界与
夜世界的视觉主题，不参与运行时模板匹配。官网宣传图没有模拟器右上角
资源栏、左下角入口等 UI，直接拿它们识别当前页面会造成误判；运行时仍以
`img/主世界圣水图标.bmp`、`img/夜世界圣水图标*.bmp` 和 `img/家乡进攻图标*.bmp`
这些游戏内 UI 模板为准。

来源：

- Builder Base 参考图：<https://support.supercell.com/clash-of-clans/en/articles/builder-base-the-basics-2.html>
- Builder Battles 参考图：<https://support.supercell.com/clash-of-clans/en/articles/builder-base-versus-battles-3.html>
- Home Village 参考图：<https://supercell.com/en/games/clashofclans/blog/news/home-village-new-levels/>
- Home Village 攻城器械页面参考：<https://support.supercell.com/clash-of-clans/en/articles/siege-machines-3.html>
- Builder Base 英雄与兵种页面参考：<https://support.supercell.com/clash-of-clans/en/articles/builder-base-heroes-troops.html>

页面与官方资料的对应关系：

- 主世界主页/建筑：Home Village 页面。
- 夜世界主页/资源/入口：About Builder Base 页面。
- 夜世界战斗/准备/第二阶段/结算：Builder Battles 页面。
- 主世界战斗/兵栏/攻城器械：Siege Machines 页面。

官方页面用于建立“页面有哪些稳定语义特征”的参考索引；运行时识别仍只使用
模拟器实际截取的游戏 UI 模板和区域特征，不把网页宣传图当作像素模板。
