# COCauto · 城控

一个用于《部落冲突》Android 模拟器的 Windows 桌面控制台。通过 ADB 连接模拟器，在界面中选择机器人、勾选任务、查看连接画面与运行日志。项目仍在持续测试中，请先用测试账号和可承受风险的资源验证。

> 本项目是独立的社区工具，与 Supercell 无关联。自动化操作可能违反游戏规则，使用者需自行承担账号风险。

## 下载与启动

从 [GitHub Releases](https://github.com/xiang0825/COCauto/releases) 下载 Windows 压缩包，**完整解压**后运行 `部落冲突.exe`。`_internal` 文件夹必须与 EXE 放在同一目录；只下载或移动单个 EXE 无法正常运行。

打开程序后：

1. 在「模拟器连接」选择 ADB 设备，确认目标是模拟器，并用「测试连接并截图」核对画面。
2. 在「任务计划」只勾选需要执行的任务，按需要调整顺序及参数。未勾选的可选任务不会被调度。
3. 回到首页确认已选任务，再点击顶部「启动」。需要排查时查看「运行日志」；可随时点击「停止」。

支持通过 ADB 连接 MuMu 等 Android 模拟器。连接状态、截图、机器人配置与任务日志都在桌面界面中查看；默认配置会自动保存。

## 当前功能与验证范围

- 可选任务计划、顺序调整、机器人管理、设备连接测试与日志筛选。
- 主世界资源 OCR、城墙升级以及已有的主／夜世界任务流程。
- 界面和启动流程已在 Windows 打包版实际打开检查；自动化逻辑有单元测试。
- 城墙升级曾在 MuMu 实机画面中完成一次从 16 级到 17 级的验证。**这不代表其它战斗、搜索、下兵或升级流程已经全部实机验证。** 游戏更新、分辨率变化或弹窗仍可能使任务停止或识别失败。
- 天鹰火炮任务与相关模型已从当前版本移除。

运行真实账号前，请确认设备截图、任务勾选和资源阈值。不要在未观察日志的情况下长时间无人值守。

## 从源码运行

项目以 Windows 和 Python 3.11 为主要开发环境，依赖请见 `requirements.txt`。安装完成后运行：

```powershell
python UI入口.py
```

运行测试：

```powershell
python -m unittest discover -s tests -q
```

构建 Windows 版使用 `自动脚本.spec`，发布目录必须同时包含 EXE 与 `_internal`。本地数据库、日志、虚拟环境及构建缓存不应上传仓库。
