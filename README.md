# COCauto

COCauto 是一个面向 Android 模拟器的《部落冲突》自动化控制台，使用 ADB 连接设备，并通过任务计划执行已配置的自动化流程。

## 当前版本特性

- MuMu、雷电、BlueStacks 等支持 ADB 的 Android 模拟器连接
- 设备连接测试、截图与 ADB 控制台
- MAA 风格的任务勾选与上下移动排序
- 资源打满后退出或待机策略
- 运行日志固定显示在主界面底部，并汇总所有机器人
- 窗口可自由缩放，布局会随窗口大小变化
- 默认只创建一个机器人，配置修改即时保存
- 不包含远程公告、统计上传或启动更新弹窗
- 进攻前扫描可见兵栏，记录槽位、数量、兵种/英雄/攻城器械/药水类别
- 下兵间隔可在“进攻选项”中设置，默认 25ms；检测回营后停止后续点击
- 主城资源 OCR 读取金币、圣水、黑水，并写入运行时状态
- 资源模式会在进攻前对资源建筑可达性进行 0~10 评分；评分严格大于 5 才会进攻，5 分及以下自动点击“下一个”
- 战斗结束强制记录胜负、星数、摧毁率、战利品目标和英雄技能识别状态

## 启动

开发环境：

```powershell
python UI入口.py
```

也可以双击 `start_coc.cmd`。发布版使用 `部落冲突助手.exe` 启动。

## ADB 连接

1. 在模拟器设置中打开 ADB 调试。
2. 在“模拟器连接”页填写 ADB 地址，例如 `127.0.0.1:5555`。
3. 点击“测试连接”，确认截图能够正常获取。
4. 在“任务计划”页勾选任务并调整顺序。
5. 回到机器人管理页启动任务。

进攻日志会显示类似“兵栏识别：共8格｜1:兵种/... x117”的诊断信息；
主世界英雄技能的精确识别需要在 `img` 中提供“英雄技能_可用.bmp”和
“英雄技能_已使用.bmp”模板，缺少模板时会明确显示“未识别”，不会把英雄已部署误报成技能已使用。

资源易窃取评分基于当前 YOLO 模型能识别的资源建筑位置、储存建筑可达性、到可进攻边缘的距离和可用入口数量；当前模型未识别防御塔、陷阱或英雄，所以日志会明确标注为“资源建筑可达性代理”。

请先使用测试账号验证流程。自动化操作真实游戏账号可能违反游戏规则并导致账号风险。
