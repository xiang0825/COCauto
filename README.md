# COCauto · 城控

一个用于《部落冲突》Android 模拟器的 Windows 桌面控制台。通过 ADB 连接模拟器，在界面中选择机器人、勾选任务、查看连接画面与运行日志。项目仍在持续测试中，请先用测试账号和可承受风险的资源验证。

> 本项目是独立的社区工具，与 Supercell 无关联。自动化操作可能违反游戏规则，使用者需自行承担账号风险。

## 下载与启动

**[下载 Windows 版（2026-11-23，rc118 测试版）](https://github.com/xiang0825/COCauto/releases/download/v2026.11.23-rc118/COCauto-Windows-2026-11-23-rc118.zip)** · [本版说明](https://github.com/xiang0825/COCauto/releases/tag/v2026.11.23-rc118) · [查看全部版本](https://github.com/xiang0825/COCauto/releases)

rc118 Windows 包包含桌面 EXE、完整运行库、模型与许可证，并自带 Python。请先安装 MuMu 等受支持的 Android 模拟器；连接时使用模拟器自带的 ADB。自动战斗的实机结果和验证范围见下方说明；小样本实测不代表长期稳定。

将 ZIP **完整解压到有写入权限的文件夹**，再运行其中的 `部落冲突.exe`。`_internal` 文件夹必须与 EXE 放在同一目录；只下载或移动单个 EXE 无法正常运行。首次运行会在程序目录创建数据库等本地数据。

打开程序后：

1. 在「模拟器连接」选择 ADB 设备，确认目标是模拟器，并用「测试连接并截图」核对画面。
2. 在「任务计划」只勾选需要执行的任务，按需要调整顺序及参数。未勾选的可选任务不会被调度。
3. 回到首页确认已选任务，再点击顶部「启动」。需要排查时查看「运行日志」；可随时点击「停止」。

在「运行日志」点击「悬浮半透明」，可打开可拖动、置顶的半透明日志小窗；将模拟器切到前台即可边看游戏边看日志。小窗顶部独立显示当前机器人、运行／暂停／停止状态和最近的关键步骤。点击「关闭悬浮」恢复普通查看方式。

本地新版支持快捷键：`F1` 开始已选机器人，暂停时按 `F1` 继续；`F2` 暂停运行中的机器人。程序运行期间，在 MuMu 游戏窗口前台也可使用。暂停的是机器人操作，**游戏倒计时不会暂停**；请避免在需要立即操作的战斗阶段长时间暂停。若快捷键被其他软件占用，可回到控制台使用顶部按钮。

支持通过 ADB 连接 MuMu 等 Android 模拟器。连接状态、截图、机器人配置与任务日志都在桌面界面中查看；默认配置会自动保存。

## 从源码运行

项目以 Windows 和 Python 3.11 为主要开发环境，依赖请见 `requirements.txt`。安装完成后运行：

```powershell
python UI入口.py
```

运行测试：

```powershell
python -m unittest discover -s tests -q
```

构建 Windows 版使用 `自动脚本.spec`，发布目录必须同时包含 EXE 与 `_internal`。本地数据库、日志、虚拟环境及构建缓存不应上传仓库。
