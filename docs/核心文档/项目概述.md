# 01 - 项目概述

> 当前产品面向普通用户的入口是 Windows 发布包中的 exe。下方是源码维护参考，不是安装或用户启动指南；手机控制与计划任务自动启动已在主线提交 `8f5276a` 中移除。

## 项目信息

**名称**：COCauto - 部落冲突自动化辅助工具

**性质**：技术学习演示项目，用于展示图像识别、自动化脚本、软件架构设计

**仓库**：https://github.com/xiang0825/COCauto

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.11（源码开发） |
| GUI | PySide6 |
| 图像识别 | YOLO v5 (ultralytics), YOLO v8 (ONNX Runtime) |
| OCR | PaddleOCR |
| 模板匹配 | OpenCV |
| 数据库 | SQLite3 |
| 模拟器控制 | ADB 设备连接 |

## 运行环境要求

- **Python**：3.11（仅源码开发；普通使用者运行发布 exe）
- **模拟器**：雷电模拟器
- **坐标适配**：任务使用 800x600 逻辑画布，ADB 截图和触控会自动映射到设备实际分辨率
- **Windows缩放**：不影响 ADB 设备坐标适配
- **操作系统**：Windows 10/11

## 启动方式

### 普通用户

完整解压 Windows 发布包后运行 `部落冲突.exe`，并保留同目录的 `_internal` 文件夹。详见 [使用说明](../使用说明.md)。

### 开发者源码运行
```bash
python UI入口.py
```

以上源码命令只供开发者使用；普通用户不使用 Python 或命令行入口。
