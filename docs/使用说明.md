# 使用说明

## 启动程序

1. 从发布包下载 Windows 版本并完整解压到可写目录。
2. 确认 `部落冲突.exe` 与 `_internal` 文件夹在同一目录。
3. 双击 `部落冲突.exe` 启动。普通使用者只用 exe；不要用 Python 脚本或命令行入口启动。
4. 按界面提示选择已运行的模拟器设备。程序不会启动或关闭模拟器；「自动启动游戏」选项只会在模拟器已运行时通过 ADB 打开游戏。

## F1 / F2

- **F1**：开始已选任务，或继续已暂停的任务。
- **F2**：暂停机器人操作。游戏内计时仍会继续；人工暂停不会触发自动重启。

也可以使用界面上的开始、暂停和停止按钮。

## 任务选项

只勾选要运行的任务；未勾选任务不会执行。设置按机器人分别保存，当前本地保存值可能不同于代码默认值，开始前请在界面确认。

- **部落竞赛接任务**：默认关闭。打开后可设置任务白名单；程序只接选定且能由主世界打鱼完成的任务，不会自动领奖。
- **资源打满后动作**：可选「退出」「待机」「继续打鱼」。默认是「退出」；继续打鱼时，超出仓库容量的战利品不会入库。
- **启动游戏**：默认开启「游戏没开时自动启动部落冲突」，通过 ADB 启动游戏，但不会启动模拟器。
- **非人工停止后自动重启任务计划**：默认开启。异常或心跳超时等停止后等待 10 分钟，并只读确认连续两帧是主世界主页才重启；连续失败 3 次后放弃。主人手动停止、F2 暂停、自然完成和内存保护暂停不会自动重启。
- **通知**：程序不再弹桌面通知、托盘气泡或推送企业微信；脚本停止、安全待命、断线重连失败、内存保护暂停、搜敌达到上限、线程异常和竞赛可领奖都只写日志，异常现场仍会留证。
- **主世界刷资源 / 进攻选项**：资源筛选、搜索放宽和集中目标数量可调整；不熟悉时保留默认值。

竞赛接任务默认值来自源码设置定义，不代表当前机器人的已保存状态。2026-11-25 发布记录标注 rc145 的实测配置启用了竞赛接任务；这不代表当前每个机器人的保存值。部落竞赛结束、积分满或可领奖时，程序只在日志里提醒；**奖励必须由主人手动选择和领取**。

## 旧版回滚

回滚时使用同一时间戳的一对旧版文件与目录，不要混搭版本：

1. 按 F2 暂停任务，正常退出程序，并备份 `数据库/任务系统.db`。
2. 将当前 `部落冲突.exe` 和 `_internal` 改名留存，避免覆盖或删除。
3. 找到对应的 `部落冲突.exe.旧版_<时间戳>` 和 `_internal.旧版_<同一时间戳>`。
4. 分别把这两个名称改回 `部落冲突.exe` 和 `_internal`。
5. 确认 exe 与 `_internal` 同目录，再启动 exe。

发布记录中可核实的旧版时间戳范围见 [rc143–rc145 发布记录](./实测/发布-2026-11-25-rc143-rc145.md)。
