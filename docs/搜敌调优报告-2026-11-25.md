## 三、数据识别的三大瓶颈与依据

### 瓶颈 1：自适应 `最低高价值可达折算 = 0.70` 过严且超出候选预算后不放宽（严重）
- **代码缺陷**：[`获取自适应资源筛选门槛`](file:///C:/Users/opa09/orca/workspaces/coc_robot/feat-search-tuning/任务流程/主世界打鱼/搜索敌人.py) 原先在第 20 个候选后仅把易窃取评分从 `6.5` 退回 `5.0`，**却让 `0.70` 高价值可达门槛在全部 150 次搜索中永久锁定**。
- **线上对比（W4 `rc141~rc147`）**：
  - 未触发自适应（n=95）：平均搜敌 **`2.80 次 / 12.7s`**，胜率 `47.4%`，摧毁率 `49.3%`。
  - 触发自适应（n=20）：平均搜敌暴涨至 **`9.85 次 / 57.2s`**（**4.5 倍耗时**，最大 43 次 / 293.5s）。
- **全样本反事实验证（W3 n=738 匹配战斗，按净入库 `家乡资源` 掠夺率分层）**：
  - `hv_adj ∈ [0%, 45%)`（n=46）：胜率 `28.3%`，真实掠夺率仅 **`38.7%`**（真内圈陷阱，应过滤）。
  - `hv_adj ∈ [45%, 55%)`（n=149）：胜率 `35.6%`，掠夺率 `57.9%`。
  - **`hv_adj ∈ [55%, 70%)`（n=241）**：胜率 **`39.0%`**，掠夺率 **`69.4%`**，平均净得 `1,198k`——**比 `>= 70%` 组（胜率 `36.1%`、掠夺率 `65.1%`、净得 `1,201k`）更稳且不损失收益**！
  - `W1` 全部 `1,207` 次 `adaptive_hv_reach` 跳过的阵营中，有 `298` 个已满足 `>= 1.4M` 且属于健康的 `[55%, 70%)` 区间，白白浪费搜索时间与金币。

### 瓶颈 2：`黑水优先` 前期门槛 `15,000 / 40 次` 与分布严重脱节（严重）
- **实测表现（`2026-11-23`，n=39 场）**：平均每场仅 YOLO 前预过滤就跳过 **`26.2 次`**（最高 58 次），单场搜索周期拉长至 `192s+`，其中 `20.5%` 的跳过阵营黑油已超过 `10,000`。
- **5,000 场蒙特卡洛模拟（基于 3,915 条纯净候选实测池）**：
  - 基线 `15,000<=40 / 8,000<=80`：均值 `23.97` 搜（P90 `43`），`116.3s` 搜索，`10.53 场/h`，**`105.9k 黑油/h`、`17.29M 金+水/h`**。
  - 调优 `11,000<=25 / 6,500<=55`：均值 **`8.28` 搜（-65.5%，P90 `18`）**，`37.8s` 搜索（**-78.5s/场**），**`13.66 场/h（+29.7%）`**，**`122.6k 黑油/h（+15.8% 达全区间峰值）`**、**`21.21M 金+水/h（+22.7%）`**。

### 瓶颈 3：基础门槛与兵力聚焦参数观察
- **基础 `资源易窃取最低评分 = 5.0` 与 `资源边缘比例 = 0.5`**：实测筛选 `> 5.0` 与 `> 5.5` 在 `边缘比例 >= 0.5` 约束下仅有 `1/907`（0.11%）候选差异，`5.0` 已具备极佳去噪能力；通过参数化保留 `5.0` 默认值（可调范围 `0.0 ~ 9.5`）兼顾向下兼容与调参自由度。
- **搜索目标递减参数（`10 次 / 10% / 100,000`）**：模拟对比 `8 次 / 12%` 与 `10 次 / 10%`：后者在修复自适应死循环后均值仅 `4.46` 搜，且不会在 8 搜时过早折价大鱼（`21.21M/h` vs `21.12M/h`）；同时修正当用户预设 `欲进攻的最小资源 < 最低下限` 时旧逻辑会反向把目标抬高到 `100,000` 的边界 bug。
- **兵力聚焦观察（`进攻.py`）**：
  - `分散探索（dirs=4, tgts=4）`（n=158）：胜率 **`48.1%`**、摧毁率 `48.0%`、掠夺率 **`72.5%`**；`分散探索（dirs=2, tgts=4）`（n=195）：胜率 `34.4%`、掠夺率 `67.7%`。
  - `集中主力（dirs=1, tgts=2）`（n=180）：胜率 `40.6%`、摧毁率 `44.2%`、掠夺率 `54.1%`。保持默认 `集中主力目标上限 = 2`（维持单边破点语义与已有测试），并将其开放为可配置项（`1~6`）；另注：当前线上 `robot_1` 未开启自动配兵（`是否自动配置军队 = False`），若启用内置 `隐秘哥布林刷资源` 预设并激活超级哥布林，资源掠夺密度可进一步放大。
