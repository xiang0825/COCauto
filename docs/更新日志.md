## Git 中可核实的功能提交

- **部落竞赛接任务与满仓继续打鱼**：`52717dc` 新增可由打鱼完成的竞赛任务，`46426ab` 改进安全点击和动态卡片布局，`f49c4ab` 增加满仓后「继续打鱼」，`6fe8f68` 合并。图片与日志证据见 [2026-11-24 部落竞赛实测](./实测/部落竞赛-2026-11-24/实测日志.txt)。
- **两批稳定性修复**：第一批为 `640643e` / `c2e4104` / `edb689e`，包括内存保护后可恢复、搜敌安全上限与待命现场保留；第二批为 `228652f` / `8b5410d`，涉及旧帧等待、资源 OCR 上限、检测器调用隔离、SQLite 连接设置、日志归档和截图轮询。细节与限制见 [rc143–rc145 发布记录](./实测/发布-2026-11-25-rc143-rc145.md)。
- **竞赛扫描与执行间隔**：`36f47c6` 将完整卡片扫描总时限从 180 秒调至 420 秒；`3e9d810` 在进攻间隙重新检查竞赛，缓解满仓继续打鱼时任务计划不再回到竞赛项的问题。
- **任务接取误报与结算识别**：`8321e8b` 用进度 `0/N` 或灰卡等证据确认接取，修正仅因找不到红色「放弃」按钮而记成超时的误报；`4298766` 等结算动画后重读页面，统计未完整时安全返回。
- **桌面通知及任务衔接**：`5ce48cb` 新增 Windows 桌面通知通道；`6ddfa42` 在任务完成后按进度尽快接新任务，并在竞赛结束、可领奖或积分满时只提醒，不点击领奖按钮。
