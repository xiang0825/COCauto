# 官方账号数据（部落冲突官方 API）

机器人可以通过部落冲突官方 API 读取你账号的英雄、研究（兵种、法术、攻城器械）和战宠等级。
目前用途是：**升级前先查官方等级，目标已经满级就跳过，不再打开面板点击。**

不配置也能正常使用，所有任务按原流程执行。

## 能做什么、不能做什么

| 能读到（官方 API） | 读不到（仍靠截图识别） |
|---|---|
| 英雄、研究、战宠的当前等级和满级 | 金币、圣水、黑油数量 |
| 已激活的超级兵种 | 正在升级的建筑、实验室正在研究什么 |
| 大本营等级、奖杯、捐兵 | 建筑工人是否空闲 |

## 第一步：申请 Token

1. 打开 <https://developer.clashofclans.com>，注册并登录（这个网站的账号与游戏里的 Supercell ID 不通用）。
2. 右上角你的名字 → **My Account** → **Create New Key**。
3. Key Name、Description 随便填；**ALLOWED IP ADDRESSES 填本机公网 IP**（可以在 <https://api.ipify.org> 查看）。
4. 点 **Create Key**，再点开刚建的 Key，复制 **TOKEN**（很长的一串）。

Token 相当于 API 密码，不要发给别人。

## 第二步：填写到机器人

在程序的 **任务计划** 页，左下「通用设置」列表最后一项 **⚙ 官方账号数据**：

| 字段 | 填什么 |
|---|---|
| 官方 API Token | 上一步复制的 Token（输入后显示为圆点） |
| 玩家标签 | 游戏内点自己的头像 → 个人资料里 `#` 开头的标签，例如 `#ABC123` |
| 同步间隔（分钟） | 两次读取官方数据的最短间隔，默认 30，范围 5～1440 |

填写后自动保存。每个机器人（账号）单独配置；多个账号可以共用同一个 Token，只要在同一台电脑上。

## 运行时会看到什么

- **开始任务时**：同步一次，运行日志出现一行摘要，例如
  `官方数据：小明（#ABC123）大本营15；英雄 野蛮人之王80/85、弓箭女皇80/85；未满级研究 12 项（野蛮人、哥布林…）；未满级战宠 2 只`
- **研究、战宠、英雄升级前**：如果设置的目标已满级，日志出现
  `官方数据显示野蛮人已满级，跳过本次研究升级；可改为：哥布林、巨人…`
  然后在下次同步前不再重复检查这个任务（其它任务照常运行）。看到这条提示，就去任务设置里把目标换成建议的未满级项。
- **英雄或建筑升级**：只有目标列表里全是英雄、而且全部满级时才跳过；列表里有建筑或未满级英雄时照常执行。
- **建议建筑升级、刷墙、刷资源**：不受影响。

## 常见问题

**日志提示「官方数据同步失败：HTTP 403 …」**
Token 填错，或者本机公网 IP 变了（重启路由器后常见）。到开发者网站用新 IP 重新建一个 Key，把新 Token 填进来。同步失败时升级任务按原流程执行，不会停止机器人。

**日志提示「HTTP 404」**
玩家标签填错。注意标签里是数字 `0`，没有字母 `O`（程序会自动把 O 换成 0）。

**公网 IP 经常变怎么办**
可以使用第三方代理 RoyaleAPI：开发者网站的 IP 白名单填 `45.79.218.79`。目前程序固定使用官方地址，如需使用代理请联系维护者。

**数据多久更新一次**
官方 API 数据本身有几分钟延迟；刚完成的升级可能要等下一次同步才反映出来。

## 数据存放

- 设置保存在程序目录 `数据库/任务系统.db` 的机器人设置里（与企业微信 Webhook 相同的方式）。
- 每次同步的摘要以状态类型「官方账号数据」存入同一数据库，可在状态历史中查看。
- 不要把 Token、玩家标签或包含账号信息的日志粘贴到公开 issue 或讨论中。
