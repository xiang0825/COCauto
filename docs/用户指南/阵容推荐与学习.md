# 阵容推荐与阵容学习

机器人**不会训练部队**：它等军队营满员后，识别兵栏里有什么兵，再按「自动配兵玩法」决定怎么下。
所以阵容要在游戏里配好，机器人负责下兵，并记录每套阵容的真实收益，帮你判断哪套更好。

## 自动配兵与阵容预设

任务计划 → 通用设置 →「⚙ 兵种选择」：打开「按设置自动配兵」，选一个**阵容预设**，或用「自定义勾选」自己勾兵种、法术和攻城器械。
每次启动刷资源前，机器人进入「编辑军队」，依次重配普通兵种、法术和攻城器械（英雄不改动）：先确认要用的单位都在列表里，再清空、添加并复核容量。

三星预设取自 2026 年第三方攻略对 TH17/TH18 主流打法的汇总（各攻略配比不一，取共同思路）。实机验证（352 人口、11 法术容量）：
根蔓骑士雪怪推进 → 根蔓×8 雪怪×7 女巫×3 天使×2（350/352），法术 11/11；隐秘哥布林刷资源 → 哥布林×88 野蛮人×88（352/352），急速×5 狂暴×3。

**战斗中的法术**：跟随类（狂暴/急速/疗伤/弹跳/隐形）在主力下完后，沿“入口 → 阵营中心”分 3 批施放；
冰冻/冰障从第 2 批起放在核心区；闪电/地震/毒药/蝙蝠/骷髅/蔓生集中在入口内圈；镜像放在最后下兵位置；
复苏和回溯需要看准时机，可以配但不会自动施放。

**能力边界**：机器人只认得金矿/金库/圣水收集器/圣水瓶，看不到防御塔、城墙和援兵，
所以做不到真人的清边、骗援兵、精确冻地狱塔。三星预设的效果是“同一入口集中推进 + 法术沿推进路线跟进”，
真实效果请看阵容学习的胜率和场均收益。

## 为什么阵容要和玩法匹配

「资源优先」玩法会把兵下到**靠边的资源建筑**附近，下兵优先级是：

隐秘哥布林 → 哥布林 → 超级野蛮人 → 野蛮人 → 弓箭手 → 瓦基丽武神

不同兵种的优先目标决定了它们能不能帮你拿资源：

| 类型 | 兵种 | 打资源时 |
|---|---|---|
| 资源型 | 隐秘哥布林、哥布林 | 优先打资源建筑，收益最高 |
| 普通 | 野蛮人、弓箭手、瓦基丽、法师、飞龙、雷龙等 | 打最近的建筑，能顺带拿资源 |
| 防御型 | 气球兵、野猪骑士、巨人、戈仑石人、戈仑冰人、攻城气球、龙骑士、根蔓骑士、熔岩猎犬 | **只打防御建筑**，几乎不贡献战利品 |

## 推荐阵容（资源优先）

第三方攻略普遍认为 TH11 以上刷资源首选**隐秘哥布林**：优先攻击资源建筑，部署后短暂隐身，
能在防御反应过来之前掏空储存罐。和本机器人「资源优先」的下兵逻辑也完全一致。

- **主力**：隐秘哥布林，约占 70%~80% 人口（需在兵营用黑油或超级药水激活，激活后持续 3 天）
- **补边**：超级野蛮人或弓箭手，清理边角建筑、吸引火力
- **攻城器械**：攻城训练营，或不带
- **法术**：急速法术、狂暴法术（隐秘哥布林冲储存罐更快）
- **英雄**：照常带上，机器人会自动释放技能

快速速刷：超级野蛮人或瓦基丽为主，少量哥布林。
稳健三星：用你最熟练的推进阵容；这个玩法以星数为目标，不评估资源适配度。

> 以上是攻略汇总的通用建议，实际效果以机器人记录的数据为准（见下文）。

## 运行时会看到什么

**阵容变化时（每次启动或换兵后第一场）**

```
阵容学习：当前阵容 雷龙x8+气球兵x22+弓箭手x2+攻城气球+飞龙公爵，与【资源优先】适配度 22%；
气球兵、攻城气球 只攻击防御建筑，打资源时基本不贡献战利品。建议在游戏里改为：隐秘哥布林为主力……
```

适配度按单位个数估算：资源型 1 分、普通 0.6 分、防御型 0 分。低于 60% 时给出建议。

**每满 5 场有收益记录**

```
阵容学习对比（按场均收益）：超级哥布林x60+超级野蛮人x10+野蛮人之王：12场 胜率58% 场均 金+620,000 水+700,000 油+5,200；……
```

每套阵容要有 10 场收益记录才参与比较。按「战利品优先级」排序：
金币/圣水/黑水只看对应资源；均衡模式下黑油按 50 倍折算。
当前用的阵容不是最好的那套时，日志会建议换回。

## 怎么判断换阵容有没有用

换阵容前先让机器人用旧阵容打满 10 场，日志里会出现旧阵容的场均金币/圣水/黑油；
换成新阵容再打满 10 场后，对比日志会把两套阵容按场均收益排好序。
刷资源看的是场均收益，不是胜率：0 星但拿满外围资源，往往比打赢一场更划算。

## 注意

- 资源净变化来自战前/战后资源截图识别，是近似值，可能混入收集或升级消耗；样本越多越可靠。
- 识别不出的兵种（兵栏显示“未匹配模板”）不计入阵容签名。
- 数据存放在数据库状态类型「阵容学习」中，只保留最新一份，最多记 12 套阵容。
